# hamburguesas
Una página web pública y 100% responsive para un negocio de hamburguesas, construida con Bootstrap 5. Incluye secciones hero, tipos de hamburguesas, testimonios y contacto con un diseño profesional y moderno.

## Estructura del Proyecto
- `index.html`: Estructura principal de la Landing Page con Bootstrap 5.
- `styles.css`: Estilos personalizados y ajustes de diseño.
- `script.js`: Interactividad y lógica del lado del cliente.
